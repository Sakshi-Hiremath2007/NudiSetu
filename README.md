# NudiSetu – Interactive Kannada Learning Platform

NudiSetu is a web-based Kannada learning platform designed to make learning Kannada accessible, engaging, and practical through everyday vocabulary, interactive lessons, quizzes, and progress tracking.

## Features

- **12 Learning Categories:** Travel, college, shopping, food, hospital, everyday conversations, greetings, family, numbers, home, emergencies, and culture.
- **Interactive Lessons:** Learn useful Kannada words and phrases for real-life situations.
- **Quizzes:** Test your understanding through interactive assessments.
- **Progress Tracking:** Track explored categories and learning progress.
- **Achievement Badges:** Celebrate learning milestones.
- **Daily Kannada Vocabulary:** Explore Kannada words, meanings, and examples.
- **Speaking Studio:** Voice-related learning features, subject to browser and device support.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Speech APIs
- Netlify

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Project Objective

NudiSetu aims to make Kannada language learning easier through practical vocabulary, interactive learning activities, and progress tracking, helping learners communicate in everyday situations and connect with Karnataka's language and culture.
